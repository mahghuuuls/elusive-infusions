# Elusive Infusions

A Minecraft 1.12.2 Forge mod. Adds infusions for Everfilling Flasks, crafted from Elusive Flora plants:
after-drink effects, flask modifiers with trade-offs, and stronger Concentrated versions.

Requires Everfilling Flasks 1.2.0 or newer and Elusive Flora 1.0.0 or newer on client and server.

Repository documentation is written at release. This file is a placeholder for the initialized
project baseline.
